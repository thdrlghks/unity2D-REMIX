# LAP

> Unity로 개발한 2D 그리드 기반 퍼즐 게임

## 프로젝트 소개

LAP은 Helltaker의 스테이지 및 퍼즐 디자인을 바탕으로 제작한 2D 그리드 기반 퍼즐 게임입니다.

플레이어는 상하좌우로 이동하며, 상자를 밀어 길을 확보하고 열쇠와 장애물 등 맵에 배치된 요소를 활용해 스테이지를 해결합니다.

본 프로젝트에서는 플레이어 조작 시스템과 인게임 오브젝트 배치를 담당했습니다.

- **장르:** 2D 퍼즐
- **개발 엔진:** Unity
- **개발 형태:** 팀 프로젝트
- **담당 업무:** 플레이어 조작 및 인게임 배치
- **원본 프로젝트:** [TeamODD/Lap](https://github.com/TeamODD/Lap)

## 담당 업무

### 1. 플레이어 조작 시스템

- 상하좌우 방향 입력을 이용한 그리드 기반 이동 구현
- 이동 입력과 캐릭터 이동 처리를 연동
- 이동 애니메이션 및 상자 밀기 동작 연동
- 맵 오브젝트와의 상호작용을 고려한 이동 처리

### 2. 상자 밀기 및 오브젝트 상호작용

- 플레이어가 상자와 상호작용할 때 이동 가능 여부를 처리
- 상자가 이동할 위치의 장애물 및 충돌 조건 확인
- 상자 이동과 플레이어 이동을 연동해 퍼즐 진행 처리
- 열쇠와 탈출구 등 맵 오브젝트를 활용한 진행 흐름 구현

## 주요 구현 요소

| 구현 요소 | 내용 |
|---|---|
| 그리드 이동 | 상하좌우 입력에 따른 칸 단위 이동 |
| 이동 입력 처리 | 이동 중 발생한 입력을 처리해 캐릭터 조작 연결 |
| 상자 밀기 | 이동 가능 여부를 확인하고 상자와 플레이어의 움직임을 연동 |
| 열쇠 및 탈출구 | 열쇠 획득 여부에 따라 탈출구 이용 가능 여부 처리 |
| 이동 횟수 | 퍼즐 진행에 따른 이동 횟수 관리 |
| 애니메이션 | 대기, 이동, 밀기 동작과 플레이어 조작 연동 |

## 프로젝트를 통해 경험한 점

플레이어 이동을 단순히 좌표를 변경하는 작업으로 구현하는 것이 아니라, 그리드 이동 규칙과 오브젝트 충돌, 애니메이션, 퍼즐 진행 조건이 서로 일관되게 동작하도록 연결하는 경험을 쌓았습니다.

또한 인게임 오브젝트의 배치가 플레이어의 이동 경로와 퍼즐 해결 과정에 영향을 주기 때문에, 조작 시스템과 맵 구성을 함께 고려하는 경험을 할 수 있었습니다.
